# openESHER

*The open Experimental System for Human-guided Engineering and Reasoning*

This is a small example and learning project for illustrating how agentic AI can work. It is meant for all 
who want to take a look behind the scene and want to understand how it works. So, three things were important 
in the initial idea: 

- You can have a local LLM run tools and do things – and solve real tasks,
- you can see how it works, tweak or customize it or even extend and develop yourself,
- you can be in control or your data and independent from closed-source models and paid services, in the sense of digital sovereignty.


## The Project

Thus, the project has two equally important parts:

1. The software
2. The openESHER GitHub pages


### The Software

openESHER is written in Python, and uses [Ollama](https://ollama.com/) for running models, either locally or in the cloud.
So, you are not limited to local models. You also have access to every cloud model you can access with Ollama.


### The openESHER GitHub pages

One of the goals is to show how agentic AI works and how such systems can be build. Documentation is crucial. 
While code should be written as understandable as it could be – you know: „The code is the document!“ – there
are some things to be told beside the code, let alone user guides and tutorials. 

This project also tries to show, *why* things are done *in that way* or another. The GitHub pages contain 
conceptual articles and background information on building agentic AI tools like openESHER.

**Note:** The openESHER GitHub pages are work-in-progress – „by design“. The grow with the software. 



## The Name

At first, it is what it says: The system is experimental, and is meant to be. At the same time it is meant to help you
work on real tasks. The tool evolved especially from the need for an independent, local and extensible 
*software engineering tool*, but it is not constrained to software engineering. Try it on other tasks, with different models.  

The name also is a kind of hommage to the Dutch artist [Maurits Cornelis Escher](https://en.wikipedia.org/wiki/M._C._Escher)
{:target="_blank"} and his famous litography ["Drawing Hands"](https://en.wikipedia.org/wiki/Drawing_Hands){:target="_blank"}, 
showing two hands that draw each other. This is a pun on how the project started: As an idea to create an AI tool 
with the help of itself, ...
