# The „openESHER“ pages

openESHER is a small example or learning project for illustrating how agentic AI can work. 
Despite that, it was designed from the beginning for solving real problems, and for checking out 
what is necessary for using LLMs in local environments, without beeing bound to model providers, and without the costs.

For getting started, you need: 

1. Ollama as a LMM runtime
2. A large language model 
3. A Python environment

(Also see [preparations]({% link preparations.md %}).)


The name is a tribute to the Dutch artist [Maurits Cornelis Escher](https://en.wikipedia.org/wiki/M._C._Escher){:target="_blank"} 
and his famous litography ["Drawing Hands"](https://en.wikipedia.org/wiki/Drawing_Hands){:target="_blank"}, 
showing two hands that draw each other. This is a pun on how the project started: As an idea to create an AI tool with the help of AI.
