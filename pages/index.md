# The „openESHER“ pages

This is a small example or learning project for illustrating how agentic AI can work. 
The name is a tribute to the Dutch artist [Maurits Cornelis Escher](https://en.wikipedia.org/wiki/M._C._Escher){:target="_blank"} and his famous litography
["Drawing Hands"](https://en.wikipedia.org/wiki/Drawing_Hands){:target="_blank"}, showing two hands that draw each other. This is a pun on how the project 
started: As an idea to create an AI tool with the help of AI.

Another main goal is understanding and empowerment for what is necessary to make use of LLMs 
in local environments, without beeing bound to model providers, and without the costs.
